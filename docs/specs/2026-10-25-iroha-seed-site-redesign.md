## 1. このサイトの目的

### 役割
**信頼・権威づけ。** 集客の受け皿ではない。

### 使われ方
紹介文・挨拶文に **URLを添えて送る**。検索で見つけてもらう想定ではない。
閲覧環境は **PC・スマホがほぼ半々**。どちらでも成立させる。

### ゴール
読み終えた相手に「**この人なら安心**」と思ってもらうこと。
その場での申し込みは目的にしない。

### 中核に置くもの
**考え方・仕事のスタンス。** 経歴と数字は、その考え方を裏付ける材料として後ろに配置する。

## 2. 全体方針

### 形式
**1ページ完結型。** 上から下に読ませる。下層ページは持たない（会社概要のみ別途検討）。

### デザインの方向（A案：人物全面型）
- ファーストビューは**人物写真を全面**に敷き、**キャッチコピーを重ねて訴求**する
- スクロール後は落ち着いたトーンに切り替え、考え方を読ませる
- 色は絞る（ネイビー／白／差し色1色を基本に、既存ロゴと調整）

### トーン
**固すぎない。親しみがある。** 一般的な企業サイトの「そっけなさ」を避けることを明確な目標とする。

そっけなさの原因と、その対策：

| 原因 | 対策 |
|---|---|
| 主語が「会社」になっている | **全編を一人称（私）で書く。**「弊社」「私たち」を使わない |
| 順調な話しかない | **遠回りや葛藤も書く。** きれいな経歴だけにしない |
| 情報が整いすぎている | 余白を広く、文字を大きく。詰め込まない |

文体は「〜いたします」ではなく「〜します」。話し言葉寄りにする。

### 会社と屋号の関係（確認済み）

- **株式会社廣創** … 法人。山本剛史は **代表取締役社長**（「代表取締役」ではない）
- **iroha Seed** … 廣創の中の **マーケティング事業部としての屋号**。独立した法人ではない

- **Top SEED** … iroha Seed の **マーケティングサービスとしてのプラン**。マーケティング顧問として継続して関わる形

```
株式会社廣創
 └ iroha Seed（マーケティング事業部の屋号）
    └ Top SEED（マーケティングサービスのプラン）
```

サイト上ではこの関係が分かるように書く。iroha Seed を独立した会社のように見せない。
**Top SEED の料金はサイトに掲載しない（本人判断）。**

### 文体の決まり

- **一人称は「僕」。「俺」は使わない（本人判断）。**
- 装飾的な見せ方（数字を並べた帯、実績カードなど）は使わない。
  内容と素材で読ませる。テンプレート的な見せ方を足すほど、よくあるサイトに近づくため。

### 使わない言葉

**「売れる仕組み再設計士」はサイトでは使わない（本人判断）。**
著書の表紙には入っているが、サイトでは名乗らない。

### 固有名詞の扱い（方針）

**たとえ話に固有名詞（球団名・施設名・企業名など）は使わない。**
意味が同じで角の立たない言い方に置き換える。

例：「ヤフードームで巨人のグッズを売る」→「野球場の売店で相手チームのグッズを並べる」

### 参考にしたサイト

[西開地 平 オフィシャルWEBサイト](https://lea-lea.site/)（11,558px・10ブロック）

借りるのは**構成の考え方のみ**。コード・素材・配色・文言は一切流用しない。
具体的に借りる点は次の3つ。

1. **「最後まで読んで、合いそうなら声をかけてください」という立て付け** — 冒頭で売り込まないと宣言し、読み手の警戒を解く
2. **人物を全面に出したファーストビュー**
3. **人生を章立てで読ませる構成**（遠回りや失敗を含める）

意図的に変える点。

- 西開地さんは親しみ・ユーモア路線（血液型、「一緒にお酒を飲む」、ステッカー特典）。こちらは**信頼・安心**が目的なので、親しみは残しつつユーモアの比重は下げる
- 構成を同じ順番でなぞらない。現サイトの資産を土台に組み直す

## 4. ③ 考え方ブロック（中核）

セルフインタビュー形式。問いに答える形で、一方的な説明にしない。

想定する問い：
- なぜ、広告やLPの前に「なぜ売れないか」から入るのか
- 具体的に、どこを見て原因を判断しているのか
- なぜ値下げに頼らなくて済むようになるのか

土台にする考え方（`iroha_seed_context.md` より）：
- 売れない原因を見抜き、心理・言葉・導線を整えながら、売れる仕組みに再設計する
- 広告屋でも制作屋でもなく、「診断」「構造改善」「再設計」「伴走」に立つ
- 比較軸を変える：他社との比較ではなく「今のまま放置する」vs「このズレを直す」

## 6. 載せないもの

### お客様の声（今回は設置しない）

Instagram に掲載しているお客様の声には、実在のものと架空のものが混在している。
**架空の声を実在のものとして掲載しない。** 理由は2つ。

1. 景品表示法のステマ規制（2023年10月〜）に抵触する可能性がある
2. このサイトの目的は「安心してもらうこと」。1件でも疑われた時点で、経歴も実績もすべて疑わしくなる

実在の方から数件いただけた時点で、⑥の後ろに追加する設計にしておく。
その際、守秘義務の範囲で「福岡・美容サロン／年商3,000万円規模」のように属性のみ記載する形は問題ない。

## 7. 技術方針

### 作り方
**React + Vite を継続。** Vercel で公開。
理由：ファーストビューの作り込みで細かい調整が効く。表示も速い。

既存の構成（`App.tsx` 667行ほか）は作り直すが、**コピーとコンテンツは資産として引き継ぐ**。

### ドメイン
**取得済み。`iroha-seed.com` を使用する。**
現状、`https://iroha-seed.com` は `https://www.iroha-seed.com/` に転送され、正常に表示されている（Vercelに接続済み・HTTP 200）。

ただし **`index.html` のOGP設定が古いアドレスのままになっている**ため、作り直しの際に修正する。

```html
<!-- 現状：vercel.app を指している -->
<meta property="og:url" content="https://iroha-seed-site.vercel.app/" />
<meta property="og:image" content="https://iroha-seed-site.vercel.app/logo.png" />
```

このままだと、FacebookやLINEでURLをシェアした際のカードが旧アドレスを参照する。
紹介文に添えて送る用途では必ず直す。あわせて `canonical` で `www` あり／なしの正式版を明示する。

### 連絡先（⑧）
- **主導線はフォーム**（現サイトにあるものを流用）
- 掲載するSNSは **Facebook・Instagram・X** の3つ（確定）
  - Facebook: `https://www.facebook.com/share/1JKihxjj6A/?mibextid=wwXIfr`
  - Instagram: `https://www.instagram.com/yamamoto.irohaseed`
  - X: `https://x.com/irohashuukyaku`
- **公式LINEは載せない**（本人判断）
- 活動情報の掲載は今後の検討事項。初版には含めない

**注意：現サイトのInstagramリンクはアカウント名が異なる**（`irohaseed.yamamoto`）。
正しいのは `yamamoto.irohaseed`。現サイトのリンクが有効かどうかは未確認。

共有時に付く計測用パラメータ（`utm_source`、`psln`、`s`、`t` など）は、掲載前に必ず外す。

## 9. ファーストビューのコピー（決定）

```
値下げは、戦略じゃない。
売れない理由を見つけて、売れる形に組み直す。
```

**名前・肩書き・法人名はファーストビューに入れない（確定）。** 左上の `iroha Seed` のみ残す。

理由：
- 紹介文に添えて送るため、相手はすでに名前を知っている。名乗り直す必要がない
- 要素が増えるとコピーに向かう視線が分散する
- 左上 `iroha Seed` と下部 `株式会社廣創` が並ぶと、どちらの会社かが一瞬わかりにくくなる

名乗りは②あいさつ、詳細は⑤歩いてきた道・⑥裏付けで行う。

採用理由：
- 12文字。特大で組んでも1行に収まり、写真を邪魔しない
- 「値下げ」という全経営者に共通する敵を名指ししている
- 著書『なぜ、あの会社は高くても選ばれるのか？』と一直線に繋がる
- 本人が普段言っていること（「集客ができないから安くする、は全く違います」）の文字版

実装上の注意：
- 各行は `whitespace-nowrap` で必ず1行に収める（「戦略じゃな／い。」と割れるため）
- 写真は `object-position: 53% 20%` で顔の位置を基準に寄せる
- 暗幕はスマホが下から、PCが左から。PCは `from-black/90 via-black/55` 程度ないと白文字が負ける
- オープニングアニメーションは入れない（開いた瞬間に読める状態にする）

## 10. 公開への切り替え手順

**ドメイン移管は発生しない。** `iroha-seed.com` はすでに Vercel に接続済みのため、実際に行うのは中身の差し替えのみ。

**方式は「別ブランチ方式」で決定。** 作業ブランチ `renew` を `main` から作成済み（2026年10月25日）。
Vercel プロジェクトを分ける方式は採用しない（ドメイン付け替え時に管理画面の操作と短時間の不通が発生するため）。

### 手順

1. **新しいサイトは別ブランチ `renew` で作る。** 公開中のサイトには一切触れない
2. **Vercel のプレビューで確認する。** 本番とは別のURLが自動発行されるので、公開中のサイトに影響を与えずに実物を確認できる
3. **PC・スマホの両方で確認する。** あわせてOGPカードの表示も確認する
4. **問題がなければ本番に反映する**（`main` にマージ）。切り替え自体は数十秒で完了する
5. **切り替え後、OGPのキャッシュを更新する。** Facebook のシェアデバッガーでURLを再取得させる（古いカードが残るのを防ぐ）

### 戻し方

Vercel は過去のデプロイを保持しているため、問題が起きた場合は**即座に前のバージョンに戻せる**。
現行コードも Git に残るため、失われるものはない。

### 注意

本番への切り替えは外部に公開される操作のため、**実行前に必ず確認を取る。**

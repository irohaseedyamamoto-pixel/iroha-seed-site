## 1. いま何を作っているか

iroha Seed（山本剛史さん）のサイトを全面的に作り直している。

- **目的**：信頼・権威づけ。集客の受け皿ではない
- **使われ方**：紹介文・挨拶文に URL を添えて送る。検索で見つけてもらう想定ではない
- **ゴール**：読み終えた相手に「この人なら安心」と思ってもらうこと
- **形式**：1ページ完結。閲覧環境は PC・スマホがほぼ半々

## 4. 決まっていること（勝手に変えない）

### 文体

- **一人称は「私」。「僕」「俺」は使わない**
- 「〜いたします」ではなく「〜します」。話し言葉寄り
- 全編を一人称で書く。「弊社」「私たち」は使わない

### 使わない言葉・表現

- **「売れる仕組み再設計士」**（著書の表紙にはあるが、サイトでは名乗らない）
- **たとえ話に固有名詞**（球団名・施設名・企業名）を使わない
- **装飾的な見せ方**（数字を並べただけの帯、実績カードなど）を使わない
- **英語の大見出し**（ABOUT / SERVICE / PROFILE など）を使わない
- **「実績」「裏付け」という呼び方**をしない（⑧は「メディア出演・出版」）
- **「社外取締役」**は使わない（登記される役職と誤解されるため）。「社外CMO」は「〜のような立場で」とたとえとして使う

### 見た目のルール（2026-10-26〜27 に決定）

- **地の色は3つだけ**：明るい地 `#faf8f4`／ベージュ `#e6dfcf`／紺 `#12161f`。同じ色を続けて並べない
- **囲み（カード）は③の悩みだけ**。囲みだらけは不可と指摘済み。単調さは囲みではなく配置の変化（見出し左固定の左右分割、写真の左右入れ替え）で崩す
- **緑**：明るい面では濃い緑 `#426b19`（ベージュ地でも比4.5以上）、紺の面ではブランドの黄緑 `seed`
- **見出し**：全セクション同じ大きさ。上に小さな日本語ラベルを付ける
- **経歴の数字**（500人・3,138個・全国3位・2,500万円・100棟）は、文中でだけ大きくする。色は本文と同じ黒（時期の緑と分ける）
- **ボタン**：最後の相談ボタン＝黄緑、Top SEED＝白、Kindle＝枠線のみ。指で押しやすい高さ44px以上
- **改行**：外すと言葉の途中で折り返されてしまう場所にだけ入れる。不要な改行は入れない
- 文字色は読みやすさの基準（小さい文字で比4.5以上、記号で3.0以上）を満たすこと

### 背景のルール（2026-10-27 に決定）

「ベタ塗りの単色だとAIが作ったように見える」という指摘を受けて入れた。**一度に全部へ広げず、決めた場所だけに入れる。**

| 手法 | 入れる場所 | 中身 |
|---|---|---|
| 紙の質感 | 明るい地だけ（②はじめに・④考え方・⑥経歴・⑨ご質問） | ごく細かいザラつき。「言われて気づく」程度の濃さ |
| 透かし文字 | ④考え方「考」、⑥経歴「道」の2か所だけ | 見出しから一文字。右下にごく薄く大きく。本人に好評 |
| 光のにじみ | ⑤サービスの紺の地だけ | 右上に緑、左下に青をごく弱く重ねる |

- **背景の縦線・横線などの線の模様は入れない。** 一度入れたが「見づらい」と本人判断で全部外した
- ベージュの地（③・⑦）と、ほかの紺の地（⑧・⑩）はベタのまま。光のにじみを広げるかは本人に確認し、「⑤だけでよい」と決まった
- 部品は `index.css` の `.paper-texture` / `.night-glow`。使い方は `RenewPage.tsx` の `Section` の `texture` / `watermark` / `glow`

### セクションの境目のつなぎ方（2026-10-27 に決定）

「背景色がまっすぐ切れて、四角い箱をスクロールしているだけに見える」という指摘を受けて入れた。

| 境目 | つなぎ方 | 指定 |
|---|---|---|
| ②はじめに → ③よくあるご相談 | 記者クラブの写真を境目にまたがせる（PC約80px・スマホ約50px食い込む） | ②に `overlapNext`、写真にマイナスの下余白 |
| ③よくあるご相談 → ④考え方 | ベージュから明るい地へ色をにじませる | ④に `blendFrom="beige"` |
| ⑥経歴 → ⑦プロフィール | 明るい地からベージュへ色をにじませる | ⑥に `fadeBottom`、⑦に `blendFrom="light"` |

- **紺の地との境目はまっすぐのまま**残す（メリハリのため。全部なめらかにするとぼんやりする）
- にじませる帯は紙の質感より手前に重ね、質感も境目からゆっくり現れるようにする
- `fadeBottom` のセクションでは、透かし文字が境目でまっすぐ切れて線に見えないよう、位置を上げている
- 写真が増えたら、またがせる境目を増やせる
- 透かしのはみ出しを切るのに `overflow: hidden` を使うと、見出しの左固定（sticky）が効かなくなる。必ず `overflow: clip` を使う
- 境目の曲線は、誠実さが軸のこのサイトには甘すぎるため使わない
- 背景だけではプロとの差は埋まりきらない。いちばん効くのは「5. 残っている作業」の写真の追加

- **年齢**（プロフィールには書かない。見る時期によって変わるため）
- **「経営者として14年」**（経歴・プロフィールと重なるため外した）

### リンク表示（OGP）

URLを送るサイトなので、リンクの見出し・説明・画像が本当の第一印象になる。`index.html` を次のように変更済み。

- 見出し：`山本剛史｜iroha Seed（株式会社廣創）`
- 説明：あいさつ文から作成（売り込み調にしない）
- 画像：`public/og-image.jpg`（人物写真を 1200×630 に切り抜き）

**画像の住所は本番ドメイン（www.iroha-seed.com）で指定しているため、新しい表示が出るのは本番切り替え後。**

### 事実の扱い

経歴・数値・肩書きは**確認済みのものだけ**を使う。推測で補わない。
過去に何度も事実の取り違えを指摘されている。迷ったら必ず本人に確認する。

## 7. 進め方のルール

### 必ず守ること

- **公開中のサイトには触らない。** 作業は `renew` ブランチのみ
- **本番への切り替えは、実行前に必ず確認を取る**
- **文言を変えるものは、先に案を見せてから入れる**（本人の指示）
- 変更したら、ブラウザで PC・スマホ両方の表示を確認してから報告する
- `npm run build` が通ることを確認してからプッシュする
- コミット・プッシュは本人に言われてから。直しは何回か続けてからまとめて反映することが多い
- 事実に関わる部分は推測で書かない。本人に確認する

### Codex との連携

`~/.claude/CLAUDE.md` の第9章に記載のとおり。判断の目安は
**「仕様書を渡せば、本人に聞かずに完成まで行けるか」**。
行けるなら Codex に渡す。途中で判断が要るなら自分でやる。

### 本人とのやりとりで分かっていること

- **指摘は的確**。「なんか違う」という感覚的な指摘でも、掘ると必ず構造的な原因がある
- テンプレート的な見せ方にはすぐ気づく。小手先の装飾は逆効果
- **やりすぎにも厳しい**。「文字だらけ」→囲みを増やしたら「囲みだらけ」と指摘された。一度に大きく振らない
- 事実の誤りには厳しい。確認を怠らない
- 音声入力を使うことがあるので、聞き取り違いに注意（例：「修行」→士業、「開業」→改行、「コモン」→顧問）

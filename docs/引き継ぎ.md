## 1. いま何を作っているか

iroha Seed（山本剛史さん）のサイトを全面的に作り直している。

- **目的**：信頼・権威づけ。集客の受け皿ではない
- **使われ方**：紹介文・挨拶文に URL を添えて送る。検索で見つけてもらう想定ではない
- **ゴール**：読み終えた相手に「この人なら安心」と思ってもらうこと
- **形式**：1ページ完結。閲覧環境は PC・スマホがほぼ半々

## 4. 決まっていること（勝手に変えない）

### 文体

- **一人称は「私」。「僕」「俺」は使わない**
- 「〜いたします」ではなく「〜します」。話し言葉寄り
- 全編を一人称で書く。「弊社」「私たち」は使わない

### 使わない言葉・表現

- **「売れる仕組み再設計士」**（著書の表紙にはあるが、サイトでは名乗らない）
- **たとえ話に固有名詞**（球団名・施設名・企業名）を使わない
- **装飾的な見せ方**（数字を並べただけの帯、実績カードなど）を使わない
  → 文脈のない数字の羅列は「AIが作ったサイト」に見える。一度入れて削除した経緯がある

### 会社と屋号の関係

```
株式会社廣創（山本剛史は代表取締役社長）
 └ iroha Seed（マーケティング事業部の屋号）
    └ Top SEED（マーケティングサービスのプラン）
```

iroha Seed を独立した会社のように見せない。

### 掲載しないもの

- **お客様の声**（Instagram に架空のものが混在しているため、実在の声が集まるまで載せない）
- **Top SEED の料金**（決まっているが非掲載。金額に触れる文章も置かない）

### 事実の扱い

経歴・数値・肩書きは**確認済みのものだけ**を使う。推測で補わない。
過去に何度も事実の取り違えを指摘されている。迷ったら必ず本人に確認する。

## 5. 残っている作業（優先順）

### A. 単調さの解消 ← **次にやること**

「背景色が変わるだけで、ずっとテキストが続く」という指摘を受けている。
参考サイトを調べて原因を特定済み。**セクションの中に「カード（面）」がないことが原因。**

参考にしたサイト：

- **株式会社コンテナ** `https://contenna.net/` — 11,036px・画像12枚。今回とほぼ同条件で単調に見えていない
- **UP Forward** `https://upforward.co.jp/` — カード＋タグ＋数字の使い方

適用する手法（素材なしで実行可能）：

1. 悩み5つをカードにする（③）
2. 診断・設計・伴走をカードにして番号を大きくする（⑤）
3. 裏付けの各項目をカードにする（⑨）
4. **数字は、その話をしている文章の中で大きくする**（⑦メロンパンの「3,138個」など）
   ※集めて並べるのは禁止。文脈の中でのみ大きくする
5. セクション見出しに小さなラベルを付ける

英語の大見出し（ABOUT / SERVICE など）は**使わない**。誠実さが軸のサイトで浮くため。

### B. 写真の追加

いまある写真は3枚のみ（人物写真・記者クラブ・ラジオ）。
**話している場面、現場、やわらかい表情**のカットが欲しい。本人が探している最中。
写真が1枚入る効果は、装飾10個分にあたる。

### C. プロフィールの追加項目

趣味・好きなこと・休日の過ごし方など。本人からの情報待ち。

### D. ⑤やっていること と ⑥Top SEED の内容の重複整理

診断・設計・伴走（3つ）と S/E/E/D（4つ）がほぼ同じ内容を説明している。
通し読みの感触次第で判断、として保留中。

### E. お客様の声・支援の実例

実在の素材が揃ってから。

### F. 本番への切り替え

新ページをトップに据え、`/renew` ルートを整理し、旧ページを片付ける。
**仕様が固まれば判断の余地がない作業なので、Codex に渡す。**
切り替えのタイミングと可否は本人と決める。

## 7. 進め方のルール

### 必ず守ること

- **公開中のサイトには触らない。** 作業は `renew` ブランチのみ
- **本番への切り替えは、実行前に必ず確認を取る**
- 変更したら、ブラウザで表示を確認してから報告する
- `npm run build` が通ることを確認してからプッシュする
- 事実に関わる部分は推測で書かない。本人に確認する

### Codex との連携

`~/.claude/CLAUDE.md` の第9章に記載のとおり。判断の目安は
**「仕様書を渡せば、本人に聞かずに完成まで行けるか」**。
行けるなら Codex に渡す。途中で判断が要るなら自分でやる。

### 本人とのやりとりで分かっていること

- **指摘は的確**。「なんか違う」という感覚的な指摘でも、掘ると必ず構造的な原因がある
- テンプレート的な見せ方にはすぐ気づく。小手先の装飾は逆効果
- 事実の誤りには厳しい。確認を怠らない
